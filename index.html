Developer reference

Designed to disappear into your existing stack. TokenForge provides a dedicated Anthropic-compatible Messages API (POST /v1/messages), precise error responses, and transparent credit settlement so you spend less time adapting infrastructure.

Setup plan

Four steps from a blank account to a traced, production request against the hosted gateway.

01

Create a scoped key

Mint a tf_live_ key. The secret is shown once; afterwards only a non-reversible hash is retained.

02

Pick an enabled model

Start with one of the 22 Messages-supported routes enabled in the live TokenForge catalogue.

03

Send the first message

Point any Anthropic SDK, Claude Code, or HTTP client at https://tokenforge.ai.studio and call POST /v1/messages.

04

Trace every response

Follow each call with x-request-id and the stable JSON error types — no silent model substitution.

Overview

The public API is versioned under /v1. Connect using any Anthropic SDK, Claude Code, or HTTP client with https://tokenforge.ai.studio as the hosted base URL. Every response includes a x-request-id header so a request can be traced without retaining your prompt content in product analytics.

Authentication

Pass your TokenForge key via the standard x-api-key or Authorization: Bearer header. The full secret appears once at creation. After that, only a non-reversible hash is retained. 

x-api-key: tf_live_your_key
anthropic-version: 2023-06-01

Messages API

POST /v1/messages accepts standard Anthropic messages and returns the standard Anthropic message envelope. Set stream: true to receive server-sent events.

cURL Copy 
curl https://tokenforge.ai.studio/v1/messages \
  -H "x-api-key: tf_live_your_key" \
  -H "anthropic-version: 2023-06-01" \
  -H "content-type: application/json" \
  -d '{
    "model": "glm-5.3",
    "max_tokens": 1024,
    "messages": [{
      "role": "user",
      "content": "Explain vector search in three lines."
    }]
  }'

Claude Code compatibility

TokenForge fully supports Anthropic-style POST /v1/messages requests for text and tool workflows from Claude Code. This endpoint accepts your TokenForge key through x-api-key or Bearer authentication and applies the same credit, model-control, and usage-log protections.

Claude Opus 5, Claude Fable 5.1, Qwen3.8 27B, Qwen 3.8 Max, GLM-5.3, and more use TokenForge’s server-side Messages gateway, preserving compatible text and tool workflows while retaining protected gateway controls. The bridge accepts Claude Code thinking-history blocks without forwarding private reasoning as ordinary prompt text. Image and document blocks are not supported.

Claude Code shell configuration

export ANTHROPIC_BASE_URL="https://tokenforge.ai.studio"
export ANTHROPIC_AUTH_TOKEN="tf_live_your_key"
export ANTHROPIC_DEFAULT_OPUS_MODEL="kimi-k3"
export ANTHROPIC_DEFAULT_SONNET_MODEL="kimi-k3"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="kimi-k3"

Credits are reserved from the maximum requested output allowance before execution, then settled from reported input and output tokens only after a successful request. Failed or cancelled requests release their reservation and receive no usage debit. See the model catalogue for final TokenForge credit rates and model details.

Request admission

TokenForge does not impose daily request, daily token, per-minute, or concurrent-request admission limits. You may make simultaneous API and Playground requests while your account is active. Model availability, platform maintenance, upstream-provider behavior, and your promotional-credit balance can still affect whether a request is accepted.

Errors

Responses use stable JSON error types and include an x-request-id for tracing. TokenForge does not emit platform rate-limit headers or reject calls because of platform request-rate, daily quota, or concurrency caps.

Code HTTP Meaning
invalid_api_key 401 The supplied TokenForge key is missing, invalid, or revoked.
model_not_found 404 The requested model is not in the active TokenForge catalogue.
model_unavailable 503 The selected route is disabled or overloaded. Choose an available model and retry.
insufficient_credits 402 Your promotional credit balance cannot cover the maximum estimated request cost.
provider_unavailable 503 The selected model is temporarily unavailable. No silent model substitution occurs.
